## English

### ✂️ Project Overview
**SnipSnap Dept.** is a modern, fully responsive concept landing page for a premium barber studio based in Kyiv. Created specifically as a high-quality portfolio project, it demonstrates the implementation of a clean minimalist aesthetic combined with robust front-end functionality.

### 🚀 Key Features
* **Native Multilingual UI:** Seamless client-side translation system (EN / UA / RU) running natively on pure JavaScript.
* **4-Step Booking System:** A modular interactive wizard (Service ➔ Barber ➔ Date & Time ➔ Contact Details).
* **Local State Persistence:** Booking submissions and selected language preferences are automatically saved locally via `localStorage`.
* **Zero-Server Voucher Download:** Generates and exports client booking confirmations into downloadable `.txt` files directly inside the browser.
* **Fully Responsive layout:** Pixel-perfect adaptive presentation from ultra-wide desktops down to mobile screens.

### 🛠️ Tech Stack & Design Architecture
* **Markup & Styles:** Semantic HTML5, CSS3 Custom Properties (variables), Flexbox/Grid for layout, and modern CSS blend modes/filters for the uniform monochrome imagery.
* **Scripting:** Modern vanilla ECMAScript (JS) using DOM manipulation, native localization dictionaries, and `Intl` API formatting.
* **Assets:** Decoupled architecture allowing quick photography changes in the `/assets` directory without modifying the code layout.

## Українська

### ✂️ Про проєкт
**SnipSnap Dept.** — це сучасний, повністю адаптивний концепт сайту-візитки для преміальної барбер-студії в Києві. Проєкт розроблено спеціально для демонстрації навичок у портфоліо. Він поєднує в собі стриману мінімалістичну естетику та розвинену інтерактивну логіку на стороні клієнта.

### 🚀 Ключовий функціонал
* **Нативна мультиязычність:** Повноцінна система локалізації (EN / UA / RU) в реальному часі, реалізована на чистому JavaScript.
* **Покроковий запис (4 кроки):** Інтерактивна форма бронювання послуг (Послуга ➔ Майстер ➔ Дата та час ➔ Контакти).
* **Збереження стану:** Вибір мови та створені демо-заявки надійно зберігаються на пристрої користувача за допомогою `localStorage`.
* **Генерація квитків офлайн:** Можливість миттєво завантажити текстовий файл `.txt` із деталями запису без використання серверної частини.
* **Адаптивна верстка:** Продуманий інтерфейс, який ідеально підлаштовується під будь-які дисплеї — від моніторів 4K до смартфонів.

### 🛠️ Технологічний стек та архітектура
* **Верстка та стилі:** Семантичний HTML5, змінні CSS3, модулі Flexbox/Grid та графічні CSS-фільтри для створення монохромного стилю зображень.
* **Логіка (JS):** Чистий JavaScript (Vanilla JS), робота з DOM-деревом, вбудовані словники перекладів та форматування через `Intl` API.
* **Оптимізація контенту:** Структурована папка `/assets`, яка дозволяє легко оновлювати фотографії майстрів чи послуг без редагування коду.

## Русский

### ✂️ О проекте
**SnipSnap Dept.** — это современный, полностью адаптивный концепт сайта-визитки для премиальной барбер-студии в Киеве. Проект разработан специально для демонстрации навыков в портфолио. Он объединяет в себе строгую минималистичную эстетику и развитую интерактивную логику на стороне клиента.

### 🚀 Ключевой функционал
* **Нативная мультиязычность:** Переключение интерфейса (EN / UA / RU) в реальном времени, реализованное на чистом JavaScript без внешних библиотек.
* **Пошаговая запись в 4 шага:** Модульный интерактивный виджет бронирования (Услуга ➔ Мастер ➔ Дата и время ➔ Контакты).
* **Локальное сохранение данных:** Выбранный язык интерфейса и созданные демо-заявки автоматически сохраняются в браузере через `localStorage`.
* **Скачивание чека без бэкенда:** Генерация и экспорт подтверждения записи в файл `.txt` прямо на стороне клиента.
* **Адаптивный дизайн:** Интерфейс полностью оптимизирован под любые экраны — от ультрашироких мониторов до мобильных устройств.

### 🛠️ Технологический стек и архитектура
* **Верстка и стили:** Семантический HTML5, CSS3-переменные, сетки Flexbox/Grid и графические CSS-фильтры для создания монохромного стиля изображений.
* **Логика (JS):** Чистый JavaScript (Vanilla JS), динамическое манипулирование DOM, встроенные словари локализации и форматирование через `Intl` API.
* **Удобство кастомизации:** Изолированная структура медиа-файлов в папке `/assets`, позволяющая менять фото мастеров и услуг без вмешательства в код.
